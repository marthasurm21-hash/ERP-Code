Mapping the Creative Economy: A Topological Analysis of Creative Specialisation and Socioeconomic Context in England and Wales (2011-2014) 

This repository contains the code used to analyse the sectoral structure
of creative economies across Travel-to-Work Areas in England and Wales.	

## Workflow

1. `01_nesta_data_prep.ipynb`
   Cleans and prepares the Nesta creative-industries employment data\
   and constructs sectoral location quotients.

2. `02_census_data_prep.ipynb`
   Processes 2011 Census socioeconomic variables and aggregates them\
   to TTWA geography.

3. `03_t_tests.ipynb`
   Conducts preliminary comparative statistical analysis.

4. `04_ball_mapper.ipynb`
   Constructs the Ball Mapper representation of TTWA creative economies.

5. `05_ball_mapper_analysis.ipynb`
   Analyses Ball Mapper memberships and socioeconomic colourations.

6. `06_robustness.ipynb`
   Conducts epsilon and axis-sensitivity checks and comparative analyses (k-means).}
